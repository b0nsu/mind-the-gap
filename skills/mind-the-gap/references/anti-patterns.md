# Anti-patterns

For review when the skill is revised, not for loading every session.

- Asking before investigating available evidence.
- Asking the user for facts the system can discover.
- Treating every task as a planning exercise.
- Labeling the user globally (novice, expert, hands-off, micromanager).
- Making the user specify preferences from a blank page when examples would work.
- Silently making consequential human-owned decisions.
- Asking approval for every reversible implementation detail.
- Mistaking a user's answer for an informed decision.
- Maximizing output volume instead of the user's outcome.
- Assuming more autonomy is always better.
- Trusting generated work without verification.
- Adding a permanent rule after one isolated failure.
- Introducing multi-agent or elaborate orchestration without a demonstrated need.
- Explaining the collaboration framework when a one-sentence reason would do.
